# Electricista Matriculado Zona Oeste

Sitio web estático y responsive para servicios eléctricos en Zona Oeste de Buenos Aires.

## Publicación
- Sitio: `index.html`
- No requiere build ni dependencias.
- Se puede publicar conectando este repositorio a Netlify o cualquier hosting estático.

## Antes de publicar
1. Reemplazar el número de ejemplo en el enlace de WhatsApp (`5490000000000`) por el número real.
2. Confirmar los servicios, localidades y datos de matrícula que se deseen mostrar.
3. Configurar el dominio y HTTPS en el proveedor de hosting.

## Desarrollo
Abrir `index.html` en un navegador.
